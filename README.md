# IoT Mini Project — Soil Moisture Monitoring & Pump Control

มินิโปรเจกต์ระบบตรวจวัดความชื้นในดินและสั่งงานปั๊มน้ำอัตโนมัติด้วยบอร์ด ESP8266 เชื่อมต่อกับแพลตฟอร์ม Blynk IoT

## การทำงานของระบบ

- **ตรวจวัดความชื้น:** อ่านค่าความชื้นจากเซนเซอร์ Soil Moisture ผ่านพอร์ตแอนะล็อก (A0)
- **แดชบอร์ด Real-time:** ส่งค่าความชื้นขึ้นแอปพลิเคชัน Blynk บนสมาร์ตโฟนผ่าน Wi-Fi (Virtual Pin V0)
- **ควบคุมปั๊มน้ำอัตโนมัติ:** เมื่อค่าความชื้นลดลงต่ำกว่าเกณฑ์ที่กำหนด ระบบจะสั่งงานรีเลย์ (Relay ผ่านพอร์ต D0) เพื่อเปิดปั๊มน้ำรดน้ำต้นไม้โดยอัตโนมัติ

## การเชื่อมต่อฮาร์ดแวร์

| อุปกรณ์ | ขาเชื่อมต่อ ESP8266 | หมายเหตุ |
|---|---|---|
| Soil Moisture Sensor | A0 (Analog Input) | อ่านระดับความชื้นในดิน |
| Relay Module | D0 (Digital Output) | สั่งตัดต่อไฟเลี้ยงปั๊มน้ำ |
| Power Supply | 3.3V / 5V, GND | ไฟเลี้ยงวงจร |

## การติดตั้งและตั้งค่า

1. เปิดไฟล์ `soil_moisture/soil_moisture.ino` ด้วย Arduino IDE
2. เลือกบอร์ดเป็น **NodeMCU 1.0 (ESP-12E Module)** หรือบอร์ด ESP8266 ที่ใช้งาน
3. ติดตั้งไลบรารี **Blynk** ใน Library Manager
4. ใส่ `BLYNK_TEMPLATE_ID`, `BLYNK_AUTH_TOKEN`, และชื่อ/รหัสผ่าน Wi-Fi ของคุณในโค้ด
5. อัปโหลดโปรแกรมลงบอร์ด พร้อมใช้งานทันที
